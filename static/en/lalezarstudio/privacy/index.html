Privacy Policy

Lalezar Studio and Lalezar Studio Pinner · Last updated: October 20, 2026

Scope

This policy covers Lalezar Studio Pinner, a private tool used only by the owner of the Lalezar Studio Etsy shop to publish Pins about the shop's own listings on the shop's own Pinterest account. The tool uses the Pinterest API.

What data is accessed?

With the account owner's explicit permission (Pinterest OAuth), the tool accesses only the owner's own Pinterest account in order to create and manage boards and Pins, and to read basic analytics (impressions, saves, clicks) for those Pins. No data from any other Pinterest user is accessed or collected.

How is data stored and shared?

Access tokens are stored only in the encrypted keychain on the owner's computer. Pin IDs and publishing status are stored locally to avoid duplicate Pins. No data is shared with third parties, sold, or used for advertising. The tool does not use cookies.

Pinterest

Use of Pinterest is subject to the Pinterest Terms of Service and Pinterest Privacy Policy.

Revoking access

Access can be revoked at any time in Pinterest settings under Security / Apps. When access is revoked, the locally stored tokens are deleted.

Shop customers

Purchases are handled entirely by Etsy; Etsy's privacy policy applies to buyer data. This tool does not access buyer information.
